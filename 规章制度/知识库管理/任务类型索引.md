# 任务类型索引

Agent 接到任务后，先在本索引中匹配任务类型，再按关键词和规范路径加载。

## 使用方法

```
任务描述 → 匹配下表 → 获取关键词 → 全文搜索/provides-search → 读规范 → 执行
```

## 任务类型表

> **使用说明**：在下方添加你的任务类型。每行一个任务。
> `provides 标签` 用于 `provides-search.py --synopsis` 快速定位。
> `BLOCKING` 规则是 Agent 不能跳过的硬性约束。

| 任务 | 关键词 | provides 标签 | BLOCKING |
|------|--------|--------------|----------|
| 示例：消化 inbox | inbox, 消化 | inbox消化, 目录分类 | 多主题必须拆分 |

## 规范加载流程

匹配到任务后：

1. 用关键词全文搜索 KB（`search_files` 或 `rg`）
2. 或用 provides 标签定位：`python3 scripts/provides-search.py --synopsis <标签>`
3. 读候选文件 frontmatter → 按 `synopsis/load/status` 筛选
4. 加载正文 → 执行 → 按规范验证

## 新增任务类型

接入新业务时，在上表中追加一行，然后更新对应的规范文件。详见 [[规章制度/知识库管理/知识库内容治理规范/10-新业务接入流程]]。
