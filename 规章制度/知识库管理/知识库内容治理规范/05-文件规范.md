# 文件规范

## 必须包含

每个 `.md` 文件必须包含 YAML frontmatter：

```yaml
---
title: "文件标题"
date: 2026-06-13
tags: [标签1, 标签2]
category: "目录路径"
load: on-demand
status: active
---
```

## 推荐字段

```yaml
---
audience: [all]
synopsis: "一句话说明这个文件管什么、何时该加载"
provides: [知识切片A]
version: 7
changelog: "_templates/ 目录名下划线合规说明本次变更摘要"
versions:
  审核规范: 3
---
```

| 字段 | 用途 | Agent 处理方式 |
|------|------|---------------|
| `load` | 加载策略：`always` / `on-demand` / `archive` / `index` / `workflow` / `template` | 必看 |
| `status` | 生命周期：`active` / `deprecated` / `draft` / `scaffold` | 跳过 deprecated/archive，draft/scaffold 仅参考 |
| `synopsis` | 一句话摘要，说明文件管什么 | **优先用于搜索后筛选** |
| `provides` | 本文件提供的语义标签 | 辅助定位，不要求受控词表登记 |
| `audience` | 人类维护者视角的读者范围 | Agent 忽略，不作为过滤条件 |
| `version` | 文件总版本号 | 实质性内容改动 +1 |
| `changelog` | 本次变更摘要 | 判断变更是否影响本地实现 |
| `versions` | provides tag 级版本号 | 可选；仅长期 cron、生产 skill、脚本依赖的核心规范需要 |

> `synopsis` 解决“搜到了但不知道该不该读”的问题，是 Agent 按需加载的第一筛选字段。`provides` 保留为语义标签和 cron 固定依赖入口，但不再要求先登记到受控词表。

## 版本号规则

| 规则 | 说明 |
|------|------|
| 初始值 | 新增 `version` 字段时统一从 `1` 开始 |
| 何时 +1 | 实质性内容改动：规则新增、修改、删除；标准调整；检查项变更 |
| 何时不变 | typo、格式、日期、重命名等非内容性改动 |
| `changelog` | 一句话说明变更，如“B5 阈值 3→5；新增 B8 响应时间检查” |
| `versions` | 按需维护；只有需要 tag 级同步的文件才必须更新 |

> 改核心规范时至少更新 `version` + `changelog`。如果文件已有 `versions` 且该文件被长期 cron / 生产 skill 依赖，则同步更新相关 tag 的版本号。

## 命名规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 使用中文 | 文件名清晰表达内容 | `内容发布流程与质量规范.md` |
| 不含空格 | 用 `-` 或直接连接 | `发布流程与质量规范.md` |
| 不含特殊字符 | 避免 `#` `&` `*` 等 | ✅ `KPI系统实现方案.md` |
| 索引文件 | 每个含 `.md` 内容的目录必须有 `index.md` | `内容合规与安全/index.md` |
| .md 扩展名 | 所有文件必须是 Markdown | `GPU分享.md` |
| `NN-` 前缀唯一 | 同一目录下编号不能重复 | `00-读取规范.md` |

## 大小限制

| 限制 | 值 | 原因 |
|------|------|------|
| 单文件行数 | ≤ 600 行 | 超 600 行仅 WARNING，不阻止 commit |
| 推荐行数 | ≤ 200 行 | 超过考虑按话题拆分 |
| 单文件大小 | ≤ 100 KB | 过大影响 Agent 加载 |
| 目录层级 | ≤ 5 层 | 实际结构需要（如 规章制度/知识库管理/知识库内容治理规范），5 层足够且可维护 |

## 交叉引用

使用纯 wiki-link 链接相关文档：双中括号内必须是完整路径，不使用竖线别名；目录索引明确写到 `/index`。

```text
- [[规章制度/知识库管理/知识库内容治理规范/index]]
```

## 目录名规则补充

- `_templates/` 目录名含下划线，**合规**。此为内部模板目录，仅供 Agent 读取骨架构造新文件，不参与 wiki-link 索引。
- 其他所有 `.md` 文件所在的目录必须使用中文命名。
