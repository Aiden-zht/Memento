# 质量检查

## 8.1 自动检查（建议）

```bash
# 基础格式和链接检查
bash scripts/lint-knowledge-base.sh

# Agent 使用风险检查
python3 scripts/audit-agent-usability.py
```

基础 lint 检查：frontmatter、文件大小、禁止模式、wiki-link。

Agent 可用性审计检查：模板是否泄漏为 active/on-demand、草稿/骨架索引是否伪装成生产入口、active index 是否无提示链接非生产文件、占位 wiki-link 是否被写成真实双链、**pre-commit hook 是否已安装**（缺失则报 E_AGENT_HOOK_MISSING）。

## 8.2 人工审查

| 审查项 | 频率 | 责任人 |
|--------|------|--------|
| 新增文件是否合规 | 每次提交 | Agent 自检 |
| 过期内容清理 | 每月 | 操作者 |
| 目录结构检查 | 每月 | 操作者 |
| index.md 索引准确性 | 每次大更新 | 操作者 |
