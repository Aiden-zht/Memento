# 新业务接入流程

> **已废弃旧流程**。所有新业务接入不再在 Memento 知识库中创建目录，改为按 [[规章制度/知识库管理/知识库内容治理规范/12-项目任务知识接入设计]] 在项目目录下创建独立项目任务知识。

## 新流程

新增业务领域时，Agent 按以下步骤操作：

1. 读取 [[规章制度/知识库管理/知识库内容治理规范/12-项目任务知识接入设计]] 完整规范
2. 读取 `_templates/（仅结构模板，非规则源）` 骨架模板
3. 在项目根目录创建 `项目知识/` 及子目录
4. 按模板填充 `index.md` 字段
5. 与用户对话逐步明确 `产物规范/` 或 `项目知识/<项目>/` 和 `专业知识/`、`素材库/` 或 `用户资料/` 内容
6. 执行自检验收

Memento 知识库只保留治理规范、通用知识和模板骨架。具体业务内容由各项目自行维护。

## 旧流程（已废弃，仅作历史参考）

旧流程在 `产物规范/ 或 项目知识/<项目>/` 下创建目录结构，已不再使用。已有业务（如示例内容发布业务）已迁移至对应项目目录的 `项目知识/` 中。
