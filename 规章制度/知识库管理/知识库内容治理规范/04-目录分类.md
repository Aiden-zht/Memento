# 目录分配规则

新文件创建时，按以下规则选择目录：

```
memento/
+-- inbox/                  # (入口) 人扔文章的地方，Agent 自动消化归类
+-- 规章制度/              # (L1) Agent 必须遵守命中的相关规则 — 正文按任务加载
|   +-- Agent协作/         # Agent 间协作规则
|   +-- 知识库管理/        # 知识库自身治理（本文件）
+-- 知识/                  # (L2) 跨领域独立知识（按需加载）
+-- 业务/                  # (L3/L4) 业务层 + 项目文档
|   +-- 写作/
|   |   +-- 通用/          # L2 写作通用规范
|   |   +-- 公众号/        # 公众号业务
|   |   +-- 小红书/        # 小红书业务
|   |   +-- 博客/          # 博客业务
|   |   +-- 项目文档/      # (L4) 项目级文档
```

> 操作备案记录于项目根目录 `{{WORKSPACE}}/操作备案.md`，不入库。

## 分类判断流程

```
新文件要存入知识库？
    |
    v
是规范/规则/标准（Agent 必须遵守命中的相关规则）？
    +-- YES -> 规章制度/
    +-- NO
            |
            v
    是某个业务领域的内容（公众号、抖音等）？
        +-- YES -> 业务/{领域}/
        |       |
        |       v
        |   是创作相关参考？ -> 业务/{领域}/创作规范/
        |   是项目文档？     -> 业务/{领域}/项目文档/
        +-- NO
                |
                v
        是跨领域独立知识（GPU、面试等）？
            +-- YES -> 知识/
            +-- NO
                    |
                    v
             是项目文档？
                +-- YES -> 业务/{领域}/项目文档/
                +-- NO -> 不存入知识库
```
